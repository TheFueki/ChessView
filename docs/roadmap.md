# ChessView Roadmap

## v1 Status

ChessView v1 is feature-complete and ready to freeze.

Implemented:

- auth
- live multiplayer games
- server-authoritative move validation
- ratings
- profiles
- history and replay
- local Stockfish analysis
- board editor and PGN import
- avatars
- time controls, timeout, reconnect, abort
- puzzles
- tournaments

## Release Rule

Do not expand the feature set before shipping v1.

The right move now is:

- freeze features
- polish documentation and release assets
- tag the release
- record the demo

## v1.1 Candidates

These are valid next steps after the v1 tag:

- puzzle streaks and puzzle rating progression
- saved studies
- opening explorer
- notifications
- tournament quality-of-life improvements

## Not v1 Work

These are intentionally not blockers for the release:

- blog/community surface
- major UI redesign
- another architecture rewrite
- broad feature expansion outside the current product scope
