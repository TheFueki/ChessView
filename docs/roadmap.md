# ChessView Roadmap

## Frozen Baseline

ChessView `v1.0.1` is the frozen refinement baseline.

The v1 surface already includes:

- auth
- live multiplayer games
- server-authoritative move validation
- ratings
- profiles
- history and replay
- local Stockfish analysis
- board editor and PGN import
- avatars
- time controls, timeout, reconnect, abort
- puzzles
- tournaments

## Repository Rule

Do not treat this repo as an open-ended feature sprint.

Prefer:

- bug fixes
- test coverage
- developer experience improvements
- operational hardening
- documentation clarity

## v1.1 Candidates

These are valid next steps after the frozen v1 baseline:

- puzzle streaks and puzzle rating progression
- saved studies
- opening explorer
- notifications
- tournament quality-of-life improvements

## Not v1 Work

These are intentionally not baseline maintenance work:

- blog/community surface
- major UI redesign
- another architecture rewrite
- broad feature expansion outside the current product scope
